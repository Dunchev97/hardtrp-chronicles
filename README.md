# Хроники HARDTRP

Сохранённые ролевые истории: 119 тем и 237 910 текстовых сообщений.

Сайт для чтения: https://dunchev97.github.io/hardtrp-chronicles/

- Поиск по текстам, названиям и участникам.
- Закладки и место чтения сохраняются в браузере.
- Переход к началу и концу квеста.
- Адаптивная версия для смартфонов.

Это статический сайт: index.html, app.js, style.css, catalog.js и файлы тем в data/. Серверная база данных и аккаунт читателя не требуются.

Все текстовые сообщения участников, включая реплики с / и //, сохранены. Вложения, пустые и служебные записи и сообщения ботов убраны. Реплики с привязкой, восстановленной по контексту, отмечены ↺. Неоднозначные фрагменты исключены.
